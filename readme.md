# 🚀 NexChat (Open source global chat application)

💬 **NexChat** is a modern real-time chat application that allows users to communicate instantly through multiple chat rooms. Users can join conversations, create custom rooms, and interact with others in real time through a clean and responsive interface.

## 💡 How It Works

1. 👤 Users choose a unique username.
2. 🏠 They automatically join the default chat room.
3. 💬 Messages are sent instantly using Socket.IO.
4. 📢 Users can create and join multiple rooms.
5. 👥 Online users and room counts update in real time.
6. ⚡ All communication happens instantly without refreshing the page.
